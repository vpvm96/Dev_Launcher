# Dev Launcher

여러 프로젝트를 그룹으로 묶고 로컬 서버와 환경변수를 관리하는 macOS 앱입니다.

## 실행

빌드된 `dist/Dev Launcher-darwin-arm64/Dev Launcher.app`을 더블클릭합니다. 응용 프로그램 폴더로 복사하면 Spotlight에서도 실행할 수 있습니다.

소스에서 실행하려면 Node.js를 설치한 환경에서 아래 명령을 실행합니다.

```sh
npm ci
npm start
```

## 사용

1. 왼쪽에서 Dearmonday 또는 Powderroom을 선택합니다.
2. 그룹의 DEV / PROD를 선택하거나 앱별로 환경을 지정합니다. PROD도 운영 설정을 사용하는 로컬 실행입니다.
3. 실행할 앱을 체크하고 선택 실행을 누릅니다. 개별 실행·종료·재시작도 가능합니다.
4. 환경 설정에서 기본값을 확인하고 변경할 키에 개인 설정을 입력합니다. 실행 중이면 저장 후 재시작합니다.
5. 그룹 추가와 앱 추가로 다른 프로젝트를 등록합니다. 폴더를 선택하면 실행 명령과 환경 파일 후보를 찾습니다.

환경 선택만으로 실행 중인 서버가 즉시 바뀌지는 않습니다. 재시작해야 변경된 설정이 적용됩니다. 앱 창을 닫으면 이 런처가 실행한 서버도 종료됩니다. 기존 터미널에서 실행한 서버는 관리하지 않습니다.

## 환경 파일

기본 환경 파일과 개인 설정을 합쳐 자식 프로세스 환경변수로 전달합니다. 기존 프로젝트의 `.env`와 `env/.env.*`는 수정하지 않습니다. 기본값 복원은 개인 설정을 제거하는 동작입니다. 기본 환경 파일 자체를 바꾸려면 기존 에디터에서 편집합니다.

실행 명령은 `package.json`의 스크립트 이름으로 등록합니다. 환경 파일 로더를 분리해 실제 서버 명령을 실행하므로 npm의 pre/post 스크립트는 실행하지 않습니다. 단순 스크립트 별칭은 지원하며, 여러 npm/yarn/pnpm 명령이 결합된 스크립트는 지원하지 않습니다.

프로젝트의 `node_modules`는 미리 설치되어 있어야 합니다. 설치·빌드·배포는 자동으로 수행하지 않습니다. 초기 등록 경로는 이 Mac의 `~/Documents/projects`를 기준으로 합니다.

앱 설정과 개인 환경값은 `~/Library/Application Support/Dev Launcher` 아래에 저장됩니다. 환경값은 로컬 파일에 저장되므로 Git에 넣거나 공유하지 않습니다. 비밀값은 화면에서 기본적으로 가려집니다.

## 개발·검증

```sh
npm test
npm run test:ui
npm run package
```

엔진 테스트는 임시 프로젝트를 만들고 프로세스 실행·종료, 환경값 우선순위와 원본 보존을 확인합니다. UI 테스트도 별도 임시 설정을 사용하며 실제 서비스는 실행하지 않습니다.

Electron의 격리된 preload API를 사용하며 외부 페이지 탐색과 원격 리소스 로드를 제한합니다. [Electron 공식 보안 가이드](https://www.electronjs.org/docs/latest/tutorial/security).
